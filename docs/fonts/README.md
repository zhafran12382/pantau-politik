# Font UI

Manrope variable Latin dari `@fontsource-variable/manrope@5.3.0`.
Sumber asli: https://github.com/sharanda/manrope
Distribusi: https://fontsource.org/fonts/manrope
Lisensi: SIL Open Font License 1.1, dibundel di `public/fonts/OFL-Manrope.txt`.

CSS mengimpor subset Latin melalui Vite; satu berkas WOFF2 yang sama di-preload oleh layout.
Seluruh permintaan font browser berasal dari situs ini sendiri. Ukuran serta hash asset
dicatat oleh audit build. Manrope merupakan font yang ditetapkan DESIGN.md.
